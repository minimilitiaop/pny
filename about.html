Project overview

PinayFlix API

A small TypeScript and Express backend for retrieving video listing data.

Made by Selov

About this project

This backend exposes JSON API routes for home, latest, longest, most popular, most viewed, random, and search listings. It uses Express for HTTP routing and Axios with Cheerio to request and parse listing pages.

Start the service with npm start. By default, it listens on port 3001 (or the port supplied through the PORT environment variable). The root route / returns a simple server-running message.
